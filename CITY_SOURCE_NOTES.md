# City generation source note

The city district is a native Three.js/Vite implementation inspired by the procedural grid-city concepts in:

https://github.com/mauriciopoppe/Three.js-City

The upstream repository was reviewed for its grid roads, randomized building blocks, parks, lamps, and city-driving world concepts. The current game does not import its legacy T3 framework or vendor bundle; the city is integrated into Subway Thots Hotel's existing renderer, HUD, hotel interior, room directory, and gameplay state.
